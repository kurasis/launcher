# Integration map

The adapters of [spec 19](spec/19-LAUNCHER-INTEGRATION.md) and [spec 02](spec/02-ARCHITECTURE.md)
mapped to this repository, as inventoried on main at `ac201e2` (2026-10-19). Paths are
relative to `src-tauri/src/` unless they start with another top-level directory. "Phase" is the
W phase in [PLAN.md](PLAN.md) that closes the gap; [ADAPTATION.md](ADAPTATION.md) explains the
decisions behind the "Change" column.

## Base launcher changes this feature needs

1. **Global activity permit** (`state/activity.rs`): gains a hosting permit for one world server
   that runs beside a game and instance backups, while installs, repairs, relocation and reset
   stay exclusive (W2). This is the only change to shared storage ownership; DATA_ROOT keeps its single process lock
   (`storage/lock.rs`, D-014) because the host lives in the same process.
2. **Demo rule**: narrowed for world launches by verified owners (ADAPTATION A2).
3. **Out-of-scope list** in `docs/spec/01-PRODUCT-AND-SCOPE.md` ("server hosting", "offline
   launch", "multiple concurrent games"): server hosting and one game beside one server are added
   for worlds by D-068; several games at once stay out of scope.
