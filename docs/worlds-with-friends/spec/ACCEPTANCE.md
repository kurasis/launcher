A45–A52 and A77 gate their respective expansion features (9 expansion cases). ## Evidence record template

For each run record case ID, build/commit, packaged artifact digest if applicable, OS/CPU/runtime tuple, fixtures versus live dependencies, exact setup, action, expected result, observed result, sanitized evidence path, outcome (`pass`, `fail`, `blocked`) and remaining limitation. A skipped matrix cell must have an explicit reason and release-policy impact.

## Required identity/admission adversarial sequence

Create two real accounts and devices. Obtain an allowed ticket for account A. Attempt to use it from B's endpoint, then attempt an alternate game profile from A's endpoint. Reject both unauthorized bindings through their actual respective trust boundaries. Revoke A during active play and during a control outage; record the close deadline. This test cannot be satisfied by validating a JSON field supplied by the client.

## Required data-loss sequence

Create a known world and record observable inventory/build/dimension state. Cleanly snapshot, advance the world, attempt a corrupt restore, then restore the good snapshot into a candidate. The corrupt attempt leaves the current world unchanged; the verified restore reproduces the known earlier state. Kill the agent at each commit boundary and prove one authoritative recoverable pointer.
